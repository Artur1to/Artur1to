## 🚀 Проекты

### 🌐 [AltTools](https://alttools.ru) — платформа онлайн-инструментов

Основной боевой проект. Сайт с коллекцией полезных инструментов: кредитные и ипотечные калькуляторы, ИМТ, нормы калорий, конвертеры, генераторы и другие утилиты.

**Стек:** `Django` `PostgreSQL` `Nginx` `Gunicorn` `VPS` `SEO`

**Статус:** VPS отключен в связи с отсутствием финансирования))

---

### 🍳 FoodStash — соцсеть для рецептов

Веб-приложение, где пользователи делятся рецептами и ищут блюда по ингредиентам, которые есть дома. Умный поиск, система подписок, лидерборд, ачивки, кастомизация профиля.

**Стек:** `Django` `SQLite` `JavaScript` `AJAX`

**Статус:** активная разработка для закрытия дисциплины в вузе.

---

### 📖 AltManga — сайт для чтения манги

Платформа для чтения манги с профилями пользователей и личными списками.

**Стек:** `Django` `SQLite` `HTML/CSS/JS`

**Статус:** личный проект, базовый функционал реализован.
